# Hell Kart

A thrilling kart racing experience in a fiery hell environment.

## Features

- Buy and own Hell Karts
- Race in a hell-themed environment
- Cooldown system to prevent spamming

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script from the [releases page](https://github.com/EnderDevelopment/hell-kart/releases).
2. Extract the files into your FiveM server's `resources` directory.
3. Import the `database.sql` file into your MySQL database.
4. Add `start hell-kart` to your `server.cfg` file.

## Usage

### Commands

There are no commands for this script. Players can interact with the Hell Kart by entering the designated hell location while in a kart.

### Permissions

There are no special permissions required for this script. Players can buy and use Hell Karts with the appropriate in-game currency.

## Configuration

The script can be configured by editing the `config.lua` file. The following options are available:

- `KartModel`: The model of the kart.
- `KartSpawn`: The spawn location of the kart.
- `KartHeading`: The heading of the kart when spawned.
- `HellLocation`: The location of the hell environment.
- `HellRadius`: The radius of the hell environment.
- `KartPrice`: The price of a Hell Kart.
- `HellEntryFee`: The entry fee to race in the hell environment.
- `CooldownTime`: The cooldown time between races in seconds.
